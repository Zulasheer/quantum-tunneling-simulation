# Quantum Tunneling Simulation

This repository contains a numerical simulation project on quantum tunneling implemented in a Jupyter Notebook.

## Focus
- quantum tunneling
- time-dependent wavefunction evolution
- numerical simulation
- Crank-Nicolson method
- computational physics

## Files
- `quantum_tunneling_simulation.ipynb` – main simulation notebook

## Summary
This project models quantum tunneling using the Crank-Nicolson method to simulate the time evolution of a quantum wave packet in the presence of a potential barrier.

## Methods / Tools
- Python
- Jupyter Notebook
- NumPy
- Matplotlib

## Notes
The notebook contains the implementation, numerical method, and results for the tunneling simulation.
